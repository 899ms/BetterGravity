# Timeslip

Interactive conversation timeline, branch navigation, trajectory extractor, and context cards for Google Antigravity.

## Features

- **Interactive Timeline Rail**: Discrete turn nodes anchored to the right side of the chat viewport with real-time health tiers and bidirectional scroll-spy.
- **Context Cards Vault**: Capture and organize side questions, architectural notes, and prompt fragments. Supports drag-and-drop insertion directly into the chat composer.
- **Trajectory Extractor**: Selectively extract user queries, agent responses, thinking traces, and tool calls. Export cleanly to Markdown, JSON, or promote directly into Context Cards.
- **TitleBar Cockpit HUD**: Circular Catppuccin-styled history clock on the window header providing quick access to cards, extractor, and rail visibility switches.
- **Live Telemetry Capsule**: Non-invasive real-time turn depth, compaction count, and conversation scale monitoring badge.
- **Zero-Reflow Performance**: Zero-blur single-layer alpha blend styling and closed-loop virtual mount convergence to eliminate UI lag.
